# Debugger Skill

## 🎭 技能定義

**技能類型**: 問題定位與修復
**技能簡稱**: Debugger
**繼承原則**: 繼承自 `AGENTS.md` 的所有核心原則
**信心水準**: 高 (≥90%) - 專注於問題解決的系統性思考

## 📋 核心職責

1. **分析失敗**: 當測試失敗或運行錯誤時介入
2. **定位Root Cause**: 找出問題的根本原因
3. **修復問題**: 提出修復方案並執行
4. **驗證修復**: 確保Bug消失且不產生新Bug

## 🧠 除錯框架

### Part 1: 問題重現

#### 1.1 穩定重現
- **重現條件**: 識別重現問題的具體條件
- **環境隔離**: 創建隔離的測試環境
- **步驟記錄**: 記錄重現問題的每個步驟
- **變數控制**: 控制變數，確保問題可重現

#### 1.2 錯誤隔離
- **範圍縮小**: 通過二分法縮小問題範圍
- **模組隔離**: 隔離受影響的模組
- **依賴排除**: 排除外部依賴的影響
- **最小案例**: 創建最小化重現案例

### Part 2: 根本原因分析

#### 2.1 日誌分析
- **錯誤訊息**: 分析錯誤訊息的含義
- **堆疊追蹤**: 分析堆疊追蹤的調用鏈
- **上下文資訊**: 分析上下文提供的資訊
- **模式識別**: 識別錯誤的模式和特徵

#### 2.2 程式碼分析
- **邏輯審視**: 審視相關程式碼的邏輯
- **資料流分析**: 分析資料的流向和變化
- **狀態檢查**: 檢查系統的狀態變化
- **邊界情況**: 檢查邊界情況的處理

#### 2.3 假設驗證
- **假設形成**: 基於分析形成假設
- **驗證設計**: 設計驗證假設的測試
- **實驗執行**: 執行實驗驗證假設
- **結果分析**: 分析實驗結果

#### 2.4 Root Cause 識別
- **根本原因**: 識別問題的根本原因
- **次要影響**: 識別次要的影響和相關問題
- **系統影響**: 評估對系統的整體影響
- **修復優先級**: 確定修復的優先級

### Part 3: 問題修復

#### 3.1 修復方案設計
- **方案生成**: 生成多個可能的修復方案
- **方案評估**: 評估每個方案的優缺點
- **風險評估**: 評估每個方案的風險
- **選擇決策**: 選擇最佳的修復方案

#### 3.2 修復實施
- **程式碼修改**: 實施程式碼的修改
- **配置調整**: 調整相關的配置
- **依賴更新**: 更新相關的依賴
- **測試驗證**: 驗證修復的有效性

#### 3.3 修復驗證
- **功能驗證**: 驗證修復的功能正確性
- **邊界驗證**: 驗證修復的邊界處理
- **性能驗證**: 驗證修復的性能影響
- **回歸測試**: 執行回歸測試確保沒有引入新問題

## 🔄 執行流程

### 階段 1：問題重現
1. 讀取錯誤報告和失敗測試
2. 創建隔離的測試環境
3. 記錄重現問題的步驟
4. 確保問題可以穩定重現

### 階段 2：根本原因分析
1. 分析錯誤訊息和堆疊追蹤
2. 審視相關程式碼的邏輯
3. 分析資料流和狀態變化
4. 識別問題的根本原因

### 階段 3：修復方案設計
1. 生成多個可能的修復方案
2. 評估每個方案的優缺點
3. 評估每個方案的風險
4. 選擇最佳的修復方案

### 階段 4：修復實施
1. 實施程式碼的修改
2. 調整相關的配置
3. 更新相關的依賴
4. 驗證修復的有效性

### 階段 5：修復驗證
1. 驗證修復的功能正確性
2. 驗證修復的邊界處理
3. 驗證修復的性能影響
4. 執行回歸測試確保沒有引入新問題

```typescript
// 範例：修復一個資料庫查詢錯誤
export class UserService {
  // 修復前的錯誤實作
  async getUserById(id: string): Promise<User> {
    // 錯誤：沒有處理id為空或無效的情況
    return await this.db.users.findOne({ id });
  }

  // 修復後的正確實作
  async getUserById(id: string): Promise<User | null> {
    // 1. 驗證輸入
    if (!id || typeof id !== 'string') {
      throw new Error('Invalid user ID');
    }

    // 2. 執行查詢
    const user = await this.db.users.findOne({ id });

    // 3. 處理查詢結果
    if (!user) {
      return null;  // 正確處理用戶不存在的情況
    }

    return user;
  }
}
```
